# Nigerian Car Market Analysis

## Project Overview

This project analyzes **1,450 car listings from the Nigerian car market** using Microsoft Excel for data cleaning and analysis and Microsoft Power BI for data visualization.

## Objectives

- Analyze car pricing patterns.
- Examine the relationship between mileage and price.
- Compare prices by import status, fuel type, transmission, and manufacturing year.
- Identify the most common car models and locations.
- Build an interactive Power BI dashboard.

## Tools Used

- **Microsoft Excel** — data cleaning and analysis
- **Microsoft Power BI** — data visualization and dashboard development
- **GitHub** — project documentation and portfolio

| Most Common Model | Toyota Camry |

## Key Findings

- **New vehicles** had the highest average price at approximately **₦39.36M**.
- **Foreign Used** vehicles averaged approximately **₦8.61M**.
- **Locally Used** vehicles averaged approximately **₦4.19M**.
- Toyota Camry was the most common model, with **181 listings**.
- The correlation between mileage and price was approximately **-0.253**, indicating a weak negative relationship.
- The ANOVA test showed a statistically significant difference in prices across import-status groups.
- The difference between automatic and manual vehicle prices was not statistically significant based on the t-test.
